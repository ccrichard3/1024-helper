# 1024 Helper

用于草榴站内日常浏览、回复辅助和回复库采样的一组油猴脚本。

## 包含文件

- `1024小助手-v1.1.user.js`
  - 主脚本
  - 提供自动点赞、限分区自动回复、回复库管理、图片/视频下载、无图模式、返回顶部等功能
- `1024回复采样器.user.js`
  - 可选采样脚本
  - 独立后台慢速采样帖子回复，补充主脚本使用的回复库

## 功能简介

### 1024小助手

- 帖子页自动点赞
- 指定分区自动随机回复
- 内置回复草稿面板，可切换、编辑、删除回复词条
- 支持主题图片 / 视频批量下载
- 支持无图模式
- 自动处理常见提示页
  - 遇到“如果您的瀏覽器沒有自動跳轉”自动进入目标页
  - 遇到“灌水預防機制已經打開，在1024秒內不能發貼”自动返回继续操作

### 1024回复采样器

- 后台低频采样指定分区帖子回复
- 自动过滤明显无效或低质量回复
- 与主脚本共用本地回复库缓存
- 命中异常状态时自动退避，避免频繁请求

## 食用方式

### 1. 安装脚本

推荐使用 Tampermonkey：

- 安装 `1024小助手-v1.1.user.js`
- 如需补充回复库，再额外安装 `1024回复采样器.user.js`

### 2. 日常使用建议

- 平时只启用 `1024小助手-v1.1.user.js` 即可
- `1024回复采样器.user.js` 建议只在后台标签页低频运行，不要同时开过多站内页面

### 3. 主脚本使用

进入帖子页后可使用右下角回复面板：

- `回复`：填入当前草稿
- `换一句`：切换下一条回复
- `List`：查看、增加、编辑、删除回复词条
- `下载`：批量下载当前帖子图片 / 视频
- `无图`：切换无图模式

### 4. 自动回复范围

当前仅对以下分区启用自动回复 / 采样：

- `fid=2`
- `fid=15`

## 备注

- 两个脚本共用本地缓存 `cl1024-reply-analytics-v1`
- 采样器额外使用 `cl1024-reply-sampler-state-v1`
- 如果只想手动使用下载、无图、回复草稿等功能，可以只保留主脚本

# 1024 项目

## 文件

- `1024小助手-v1.1.user.js`
- `1024回复采样器.user.js`

## 当前结构

主脚本和采样器已经拆开：

- `1024小助手-v1.1.user.js`
  只负责帖子页自动点赞、限分区自动随机回复、回复清单维护、下载、无图、返回顶部
- `1024回复采样器.user.js`
  只负责独立后台采样回复，慢速抓取、控制频率、命中 `403` 后退避

两者共用同一份本地缓存：

- `cl1024-reply-analytics-v1`

采样器额外使用：

- `cl1024-reply-sampler-state-v1`

## 自动回复范围

当前只对以下分区启用：

- 亚洲无码原创区 `fid=2`
- 亚洲有码原创区 `fid=15`

## 采样范围

当前只从以下分区采样回复：

- 亚洲无码原创区 `fid=2`
- 亚洲有码原创区 `fid=15`

## 采样策略

- 单次只抓少量版页和帖子
- 每次请求之间随机延迟 `5-60` 秒
- 每轮运行结束后进入 `25-70` 分钟冷却
- 命中 `403` 后暂停 `12` 小时
- 处理过的帖子 `12` 小时后可重新进入采样范围

## 主脚本悬浮窗

第一行：

- `回复`
- `换一句`
- `List`

第二行：

- `下载`
- `无图`

补充：

- 标题可拖动
- 再次点击标题可折叠到右侧，透明度降低
- `List` 内可直接新增、双击编辑、删除词条

## 建议用法

- 日常使用时只看主脚本即可
- 想补充回复库时，再额外启用采样器
- 采样器适合挂在站内后台标签页慢慢跑，不要同时开太多站内页面
